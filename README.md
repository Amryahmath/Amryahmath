## 🧠 AI Engineering Stack

> How I think about building an AI feature — from raw documents to something a user can trust.

```mermaid
flowchart LR
    A["📄 Raw Data<br/>docs · records · forms"] --> B["🧹 Preprocess<br/>clean · chunk · label"]
    B --> C["🔢 Embeddings<br/>vector store"]
    B --> D["📊 Classical ML<br/>scikit-learn"]

    C --> E["🔍 Retriever<br/>semantic search"]
    E --> F["🧠 LLM Reasoning<br/>grounded prompt"]
    D --> G["📈 Prediction<br/>score + confidence"]

    F --> H["🤖 Agent Layer<br/>tools · actions"]
    G --> H
    H --> I["✅ Application<br/>web · mobile · API"]

    classDef data fill:#0D1117,stroke:#1F6FEB,stroke-width:2px,color:#C9D1D9
    classDef ml fill:#0D1117,stroke:#58A6FF,stroke-width:2px,color:#C9D1D9
    classDef out fill:#0D1117,stroke:#3FB950,stroke-width:2px,color:#C9D1D9

    class A,B,C data
    class D,E,F,G ml
    class H,I out
```

**Retrieval keeps it honest · Classical ML keeps it measurable · Agents make it useful**
